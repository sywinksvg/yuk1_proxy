# 01 · 安装与配置

## 一、装依赖

### 1. Python

需要 **Python 3.10 或更高**。检查：

```bash
python --version
```

没有就去 https://www.python.org/downloads/ 装（Windows 安装时勾选 “Add to PATH”）。

### 2. uv（推荐）

`uv` 会自动为本项目建一个独立环境装依赖，不污染你的全局 Python：

```bash
pip install uv
uv --version
```

不想用 uv 也行，见本节末尾「方案 B」。

### 3. 一键安装（Windows）

双击或在 PowerShell 里跑：

```powershell
powershell -ExecutionPolicy Bypass -File install.ps1
```

它会：建 `.venv` → 装 `mcp` 与 `requests[socks]` → 打印验证命令。

---

## 二、验证服务能启动

```bash
cd server
uv run python mcp_yuk1_proxy.py
```

**没有任何输出、光标停住** = 正常（MCP 走 stdio，等客户端发消息）。`Ctrl+C` 退出。

想验证功能，另开一个终端跑命令行模式：

```bash
cd server
uv run python yuk1_proxy.py fetch                  # 拉一批免费代理
uv run python yuk1_proxy.py doctor                 # 看本机出口 + 池子状态
```

## 三、接入 MCP 客户端

MCP 的接入方式是「告诉客户端怎么启动这个进程」——**与具体客户端无关**，
下面这段核心配置换个外壳就能用。配置片段见 `examples/mcp-config.json`。

**核心配置**（把 `--directory` 换成你解压后的 `server` 目录绝对路径）：

```json
{
  "yuk1_proxy": {
    "command": "uv",
    "args": ["run", "--directory", "<解压路径>/yuk1_proxy/server", "python", "mcp_yuk1_proxy.py"]
  }
}
```

> `command` 建议写 `uv` 的**绝对路径**（`where uv` 查），避免客户端找不到 PATH。

### ZCode / YuCode

编辑 `~/.zcode/cli/config.json`，在 `mcp.servers` 里加：

```json
{
  "mcp": {
    "servers": {
      "yuk1_proxy": {
        "command": "uv",
        "args": ["run", "--directory", "C:\\path\\to\\server", "python", "mcp_yuk1_proxy.py"]
      }
    }
  }
}
```
```

### Claude Desktop

配置文件：

- Windows：`%APPDATA%\Claude\claude_desktop_config.json`
- macOS：`~/Library/Application Support/Claude/claude_desktop_config.json`

```json
{
  "mcpServers": {
    "yuk1_proxy": {
      "command": "uv",
      "args": ["run", "--directory", "/abs/path/to/server", "python", "mcp_yuk1_proxy.py"]
    }
  }
}
```

### Cursor / 其他兼容 MCP 的客户端

同理：加一个 `command` + `args` 的 stdio server 条目即可。字段名通常是 `mcpServers` 或 `mcp.servers`，
先看你客户端的文档。

### 关键：改完要重启客户端

MCP 服务在**客户端启动时**被拉起并注入环境变量。改了配置/环境变量后必须**重启客户端
（或新开会话）**才生效。

## 四、方案 B：不用 uv

如果客户端环境不方便用 uv，直接用 venv 里的 Python：

```bash
cd server
python -m venv .venv
.venv\Scripts\pip install -r requirements.txt      # Windows
# source .venv/bin/pip install -r requirements.txt # macOS/Linux
```

然后配置里把 `command` 指向 venv 的 python：

```json
{ "command": "<解压路径>/server/.venv/Scripts/python.exe",
  "args": ["<解压路径>/server/mcp_yuk1_proxy.py"] }
```

`requirements.txt` 内容（若不存在可自建）：

```
mcp>=1.9.0,<2
requests[socks]>=2.31
```

## 五、配置项（环境变量）

在客户端的 MCP 条目里加 `env` 字段即可覆盖：

| 变量 | 作用 | 默认 |
|---|---|---|
| `YUK1_PROXY_DATA` | 数据目录（池文件/缓存放这） | `~/.yuk1_proxy/data` |
| `YUK1_PROXY_UPSTREAM` | 本地上游代理，GitHub 类源走它（如 `http://127.0.0.1:7890`） | 自动探测常见端口 |
| `YUK1_PROXY_ALLOW_DIRECT` | 池空时是否允许直连兜底；置 `0` → 回 502，不漏本机 IP | `1` |
| `YUK1_PROXY_ENABLE_NPS` | 启用 nps 采集源（**默认关**，见 README 说明） | 空（关闭） |
| `YUK1_PROXY_FOFA_Q` | 启用 nps 源时，指向 `fofa_q.py` 的路径（**本包不含该脚本**） | 同目录 |

示例：

```json
{
  "command": "uv",
  "args": ["run", "--directory", "<路径>/server", "python", "mcp_yuk1_proxy.py"],
  "env": { "YUK1_PROXY_DATA": "D:\\yuk1_proxy-data" }
}
```

详见 `docs/03-配置参考.md`。
