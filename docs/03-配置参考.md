# 03 · 配置参考

## 一、环境变量

| 变量 | 作用 | 默认值 |
|---|---|---|
| `YUK1_PROXY_DATA` | **数据目录**（池文件、缓存、元数据都在这里） | `~/.yuk1_proxy/data` |
| `YUK1_PROXY_ENABLE_NPS` | 启用 nps 采集源（高级，默认关闭） | 空（关闭） |
| `YUK1_PROXY_FOFA_Q` | 启用 nps 源时，`fofa_q.py` 的位置 | 与脚本同目录 |

在 MCP 客户端配置里用 `env` 注入，例如：

```json
{
  "command": "uv",
  "args": ["run", "--directory", "<路径>/server", "python", "mcp_yuk1_proxy.py"],
  "env": { "YUK1_PROXY_DATA": "D:\\my-proxy-data" }
}
```

## 二、数据目录里的文件

| 文件 | 内容 | 要不要手改 |
|---|---|---|
| `raw.txt` | 原始池（拉取到、未验活的） | 不用 |
| `ok.txt` | 对目标验活通过的 | 不用 |
| `cn_ok.txt` | 确认中国出口的 | 不用 |
| `ok_10001.txt` | 统一入口(10001)在用的池 | 不用 |
| `paid.txt` | **你自己的付费代理**（见下） | ✅ **要手填** |
| `nps_raw.txt` | nps 源采集到的 socks5 条目 | 不用 |
| `nps_meta.json` | 上面每条的出口 IP / ISP / 对端备注 | 查看用 |
| `nps_fofa_*.json` | nps 源的候选缓存 | 不用 |

## 三、付费代理接入（强烈推荐）

免费代理寿命短、可用率低。要**稳定**，用你自己的住宅代理：

编辑 `<数据目录>/paid.txt`，一行一个：

```
1.2.3.4:8080
user:pass@5.6.7.8:3128
socks5h://user:pass@9.10.11.12:1080
```

支持三种格式：`ip:port`（HTTP 代理）、`user:pass@ip:port`、`socks5h://...`（socks5）。

- 付费代理会被**自动并入池子并优先使用**（排序靠前），不参与免费源的验证消耗
- 打国内目标建议用**住宅/移动 IP** 的代理
- 注释行以 `#` 开头会被忽略

---

## 四、`serve` 统一入口参数

```bash
python yuk1_proxy.py serve \
    --port 10001 \        # 监听端口
    --entry-port 10001 \  # 用哪个 ok 池（对应 ok_<port>.txt）
    --tries 6 \           # 单个请求最多试几个上游
    --watch 120 \         # 存活巡检间隔秒（0=关）
    --auto-harvest 200    # 池子见底自动补采的候选数（0=关）
```

## 五、nps 源（可选，默认关闭）

### 是什么

nps（ehang-io，Go 内网穿透）默认配置存在认证缺陷（CVE-2022-40494）：其 `nps.conf` 里
`auth_key` 默认被注释 → 签名退化为 `MD5(时间戳)`，任意请求带对应参数即取得管理员权限。
管理员面板里列出的 socks5 隧道，每条都是一个**现成的 socks5 代理**，出口在对端机器所在的网络。

### 怎么开

1. 准备一个 FOFA 账号与 `fofa_q.py`（FOFA 查询脚本，需另配）
2. 设置环境变量：

```
YUK1_PROXY_ENABLE_NPS=1
YUK1_PROXY_FOFA_Q=<fofa_q.py 的绝对路径>
```

3. 调用 `yuk1_nps_harvest(probe=300, skip_fofa=true)`

### 已知行为

- 多数 socks5 端口会被云安全组挡住（管理员只放行了在用的端口）
- 只有对端客户端**在线**时隧道才可用
- 正确率靠量堆：约 300 台候选出 1 台可用

### ⚠️ 边界与风险（务必阅读）

- **性质**：这是使用**他人服务器**的资源。面板的流量统计会变化、连接的目标域名对
  nps 控制者可见（socks5 只转发 TCP，TLS 内容安全但元数据透明）
- **授权**：仅在你有明确授权的安全研究/渗透测试场景启用，使用后果自负
- **默认关闭**就是为了避免误用——不开，工具包就是一个纯净的公开代理池

## 六、代理源说明

免费源在 `yuk1_proxy.py` 顶部的 `SOURCES_DIRECT` / `SOURCES_GITHUB` / `SOURCES_CN` 三个列表里，
可以自行增删：

```python
SOURCES_DIRECT = [ ... ]   # 直连可取的源
SOURCES_GITHUB = [ ... ]   # 需要梯子的源（走 Clash 7897）
SOURCES_CN     = [ ... ]   # 号称中国 IP 的源
```

加源方法：往列表里加一个能返回 `ip:port` 文本行的 URL 即可（每行一个）。

---

## 七、系统代理隔离（设计说明）

脚本**永远不读系统代理/环境变量**（`trust_env = False`），全程用独立会话。
所以它不会干扰你本机的 Clash / 系统代理，也不会被它们干扰。

唯一例外：拉取 GitHub 类源时会**显式**走 `127.0.0.1:7897`（可用则用，不可用快速跳过）。
