# 04 · 常见问题与排障

## 客户端里看不到工具 / 工具列表是空的

1. **改完配置没重启**：MCP 服务在客户端启动时拉起，必须**重启客户端或新开会话**
2. **`command` 找不到**：把 `uv` 换成绝对路径（`where uv` 查出来），客户端可能不继承你的 PATH
3. **路径写错**：`--directory` 后面必须是 `server` 目录的**绝对路径**，且该目录里确实有
   `mcp_yuk1_proxy.py`。手动跑一遍验证：
   ```bash
   uv run --directory <路径>/server python mcp_yuk1_proxy.py
   ```
   报 `系统找不到指定的路径` = 路径不存在（多半是层级搞错）
4. **依赖没装**：手动 `uv sync --directory <路径>/server` 预热一次

> 经验：**首次启动慢**是因为 uv 要建环境装依赖（30 来个包），可能超过客户端启动超时 →
> 显示「进程启动失败」。**先手动 `uv sync` 预热一次**，之后启动是毫秒级。

---

## 报「MCP 进程启动失败」

按顺序排查：

1. 手动跑 `uv run --directory <路径>/server python mcp_yuk1_proxy.py`，看报什么错
2. 报 `No module named 'mcp'` → 依赖没装，`uv sync`
3. 报路径不存在 → 检查 `--directory`
4. 秒退无输出 → 看客户端日志（通常在客户端的日志目录）

---

## 池子一直是 0 可用

免费代理的正常状态就是**波动大**。按顺序试：

1. `yuk1_check(目标首页)` 重新验活一轮（池文件是上次验证的快照，会过期）
2. `uv run python yuk1_proxy.py fetch` 重新拉源
3. **配 `paid.txt`**（自己的付费代理）——这是唯一稳定的方案，见 `docs/03-配置参考.md`
4. 打国内目标务必 `cn_only=true`

---

## 显示 200 但好像没走代理？

**直连兜底**设计：池全挂/为空时，统一入口会用你本机 IP 直连（保证入口不失效）。
判断是否真走了代理：

- 访问一个显示 IP 的页面比对：`curl -x http://127.0.0.1:10001 https://api.ipify.org`
- 看入口日志有没有 `[direct] ... 直连兜底` 那行
- 用 `yuk1_check` 的归属字段

---

## 换出口了还是被拦

先判断是**频率防护**还是**IP 封禁**：

| 现象 | 判据 | 对策 |
|---|---|---|
| 整站 000 / 几十秒后自愈 | 频率防护 | **降频**，换 IP 反而更糟（代理 IP 信誉更差） |
| 一直 403 / 验证码，换 IP 后能进 | IP 封禁 | 换出口（`yuk1_escape`） |

`yuk1_escape` 返回的 `trace` 能帮你判断：如果 `waf_check` 筛出的可用出口是 0，
说明现有池全打不动，更可能是频率防护或需要更好的 IP。

---

## 想让请求一定不走我本机 IP

统一入口有直连兜底，做不到「绝对不从本机出」。要强制走代理，用 `yuk1_fetch`（不经入口），
它在池空时直接返回失败而不是直连。

---

## 几个代理可以同时打同一个站吗

默认轮转已经处理了：同一轮内同一代理 ≤3 枪、同目标优先复用上次成功的。
不建议手动指定固定代理——列表页刷新一次就可能失效。

---

## 能用于哪些场景

任何需要「换个 IP 出网」的场景。**但请注意**：

1. **不要用免费代理传登录态 Cookie / 长期凭据**（不可信中间人能看到明文 HTTP；HTTPS 只保内容不保元数据）
2. 一次性测试凭据可以
3. 是否允许使用代理访问某目标，取决于你的授权范围——自行判断

---

## 数据存在哪 / 怎么清空

默认 `~/.yuk1_proxy/data`（可用 `YUK1_PROXY_DATA` 改）。
要重置：**直接删掉该目录**即可，下次运行自动重建。池文件都是可再生的，删了不影响。

---

## 还不行

按这个顺序抓证据，问题基本能定位：

```bash
uv run python yuk1_proxy.py doctor                 # 本机出口 + 池子状态 + 入口状态
tail <数据目录>/_serve10001.log                    # 入口日志（巡检/拉黑/兜底都记在这）
```

把报错原文 + `doctor` 输出贴出来，基本一看就知道。
